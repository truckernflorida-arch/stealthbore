## How to Go Live (Free Options)

### Option 1: Netlify (Easiest – Drag & Drop)
1. Go to [https://app.netlify.com/drop](https://app.netlify.com/drop)
2. Drag the entire `stealthbore` folder (or just `index.html`) onto the page
3. Get an instant free URL like `random-name.netlify.app`
4. Optional: Connect a custom domain (e.g. stealthbore.com) later

### Option 2: GitHub Pages
1. Create a new GitHub repository named `stealthbore` (or `stealthborellc`)
2. Upload the `index.html` file
3. Go to Settings → Pages → Deploy from main branch
4. Site will be live at `https://yourusername.github.io/stealthbore`

### Option 3: Cloudflare Pages / Vercel / Static.run
Any free static host works. Just upload the folder.

## Custom Domain
Once live, point a domain (stealthbore.com, stealthborellc.com, etc.) to the host. Most free hosts give free SSL.
